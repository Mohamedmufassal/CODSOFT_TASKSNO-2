# 📋 Task Manager

A responsive and user-friendly Task Manager application built with React.js.  
The application helps users create, organize, track, and manage their daily tasks with features such as priority management, categories, due dates, search, filtering, local storage, dark mode, progress tracking, and toast notifications.

### 🌐 Live Demo

Check out the live application here: [Live Demo](https://codsoft-tasksno-2-wo2c.onrender.com)

### 📝 Task Management
- Create new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed or pending
- Display task details in organized cards

### 🎯 Task Organization
- Assign priorities:
  - 🔴 High
  - 🟠 Medium
  - 🟢 Low
- Assign categories to tasks
- Add due dates
- View task information clearly

### 🔍 Search & Filtering
- Search tasks by task name
- Filter tasks by completion status
- Filter tasks by priority
- Dynamically update the displayed task list

### 💾 Local Storage
- Tasks are stored in the browser's `localStorage`
- Tasks remain available after refreshing the page
- No external database is required

### 📊 Task Progress
- Displays total tasks
- Displays completed tasks
- Displays pending tasks
- Dynamic progress percentage
- Visual progress bar that updates when tasks are completed

### 🔔 Notifications
- Success notification when a task is added
- Notification when a task is deleted
- Notification when a task is updated
- Notification when task status changes

### 🌙 Dark Mode
- Toggle between light and dark themes
- Improves usability in different lighting conditions

### 📱 Responsive Design
- Responsive layout for desktop
- Tablet-friendly layout
- Mobile-friendly task cards and forms

### 🎨 User Interface
- Clean and modern layout
- Card-based task design
- Priority badges
- Empty-state message when no tasks are available
- Interactive buttons and hover effects
